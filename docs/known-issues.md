# 알려진 문제

## 게임 간 Model 저장 상태 충돌

교육용 패널 제거 전 커밋 `1b4a330835c2c40aa1f8f551b9b45272fdd4023b`에서도 재현했다.

1. 새 브라우저 프로필에서 빈 게임을 불러와 실행한 뒤 닫는다.
2. 클릭 카운터 템플릿으로 변경해 실행한다.
3. 두 게임의 진입점과 표시 타입 이름이 `main` / `Model`로 같아 이전 게임의 다른 구조의 모델이 복원된다.

`startGameIfProgram`은 저장된 entry와 표시 타입 이름만 비교하며, `runtime.js`의 restore는 모델을 그대로 복원한다. 이 때문에 evaluator의 fieldwise 계산에서 `TypeError: Cannot read properties of undefined (reading '0')`가 발생할 수 있다. 발생 시점은 경과 시간에 따라 달라진다.

패널 제거 검증에서 일반 UI 43개 중 42개가 통과했고, JSON 가져오기 후 게임 전환 시나리오에서 이 문제와 연관 페이지 오류가 남았다. 새 프로필의 단독 클리커 실행·클릭·Reset·재실행, 패턴 매칭 UI 6개, 단위 테스트 451개와 빌드는 통과했다. 테스트는 삭제하거나 비활성화하지 않았다.

이 문제는 교육용 UI 제거와 별도이며, 데이터 삭제나 실행기 변경으로 우회하지 않았다. 후속 수정에서는 저장 상태를 프로젝트/모델 구조별로 구분하고 호환성을 검사해야 한다.
